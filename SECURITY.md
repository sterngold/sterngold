# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security problems involving profile assets,
linked projects, or accidental disclosure of private context. Use GitHub private
vulnerability reporting if it is available, or email the maintainer listed on
the profile.

Include:

- The affected repository, link, or asset.
- A short description of the issue.
- Reproduction steps or evidence.
- Whether private data, tokens, or local-only context may be involved.
