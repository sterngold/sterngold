# Security Policy

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities, profile-link abuse,
accidental disclosure, or private-context exposure involving this profile
repository or linked projects.

Use GitHub private vulnerability reporting for this repository:

https://github.com/sterngold/sterngold/security/advisories/new

Include:

- The affected repository, link, asset, or Git history reference.
- A short description of the issue.
- Reproduction steps or evidence.
- Whether private data, tokens, or local-only context may be involved.

If the issue involves an active credential, revoke or rotate it first before
requesting any Git history rewrite.
